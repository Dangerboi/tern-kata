## Agent skills

### Issue tracker

Issues live in kata (project `tern-kata`), driven through the `kata` CLI. See `docs/agents/issue-tracker.md`.

In chat, write ticket references as `[<id>](https://kata.invalid/tern-kata/<id>)`: the window plugin opens them in tern-kata. Tern draws `kata://` links in chat as plain text.

### Triage labels

Default five-role vocabulary, applied as kata labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
